# Destino China

A personal travel planner and cultural atlas for a journey through China. The site combines an interactive route map, a locally saved preparation checklist, a budget calculator, destination notes and longer cultural essays.

## Explore the project

Open `index.html` to use the planner. The first route follows Beijing, Tianjin, Jinan, Suzhou and Shanghai, loosely tracing the Grand Canal south toward the Yangtze Delta.

## Built with

- Semantic HTML and responsive CSS
- Vanilla JavaScript
- Leaflet and OpenStreetMap for the interactive route
- Browser local storage for checklist progress

## Project structure

```text
assets/                 Styles and interactive behaviour
destination/            Expandable city research notes
itineraries/            Thematic route plans
logistics/               Practical travel research
index.html               Interactive planner and atlas
openingceremony.html     Published cultural essay
openingceremony.md       Original working draft
```

This is deliberately a living archive: cities, routes and essays can be added as the journey develops.
